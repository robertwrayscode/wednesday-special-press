# Wednesday Special Press

Website for Wednesday Special Press, the publishing house of Wednesday Special, LLC (Houston, Texas).
Live at https://wednesdayspecialpress.com (GitHub Pages from the `main` branch).

Pages: home (`index.html`), `groundswell/`, `about/`, `contact/`, `404.html`. Shared styles in `assets/style.css`.
Keep the `CNAME` file in the root, or the domain stops working.

Photographs of Patrick Renner's artwork are not yet on the site; striped placeholder panels stand in until they are cleared for the web.
